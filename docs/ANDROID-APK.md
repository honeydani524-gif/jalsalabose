# Android APK Build

The app is packaged with Capacitor 8 as a local Android application.

## Toolchain
- Node.js 22
- Java 21
- Android SDK Platform 36
- Android Build Tools 35.0.0
- Capacitor 8.6.2

## Build locally

```bash
npm ci
npm run android:sync
cd android
./gradlew assembleDebug
```

The debug APK is generated at:

`android/app/build/outputs/apk/debug/app-debug.apk`

On Windows, run `gradlew.bat assembleDebug` from the `android` directory.

## GitHub Actions build

Pushes and pull requests run the financial tests, TypeScript check, and web production build only. They do not create an APK.

To create a debug APK later, open **Actions → Verify app and optionally build Android APK → Run workflow**, enable `build_apk`, and start the workflow. After the Android job succeeds, download the `jalsalabose-android-debug` artifact from that run.

## Local data behavior

- The Android app loads the bundled Vite build; it does not require a hosted app server.
- App data remains in the app's local WebView IndexedDB.
- Android automatic app backup is disabled in the manifest to avoid cloud/device backup of this local data.
- Use the app's own backup/export feature before changing phones or reinstalling.

## Signing note

The current APK is a CI debug build. It is suitable for initial installation and testing. Debug signing keys are generated by the build runner and are not a stable release identity across separate CI runs. Before distributing upgrades that must install over an existing copy without uninstalling (and preserve its local data), configure one persistent release keystore and keep its passwords in GitHub Actions secrets.
